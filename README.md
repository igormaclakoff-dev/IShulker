# IShulker — от AuraCode

Открывайте шалкеры **прямо из руки**: зажмите Shift и нажмите ПКМ по воздуху, держа шалкер в главной руке. Шалкер не ставится на землю — сразу открывается его содержимое.

## Возможности

- **Открытие из руки** — Shift + ПКМ по воздуху с шалкером в главной руке.
- **Защита от дюпов** — открытый шалкер нельзя выкинуть, переложить в руке или хотбар, обменять с офхендом, а внутрь нельзя положить другой шалкер.
- **Автосохранение** — содержимое периодически записывается обратно в предмет, чтобы краш сервера не привёл к дюпу.
- **Включение/выключение в игре** — `/ishulker on|off`, глобально для всего сервера.
- **Гибкие настройки** — требование Shift, триггер по воздуху/блоку, право, и т.д.
- **MiniMessage** — все сообщения настраиваются, поддержка HEX и градиентов.

## Команды

| Команда | Описание | Право |
|---|---|---|
| `/ishulker status` | Показать текущее состояние | `ishulker.admin` |
| `/ishulker on\|off` | Включить/выключить функцию | `ishulker.admin` |
| `/ishulker toggle` | Переключить функцию | `ishulker.admin` |
| `/ishulker reload` | Перезагрузить конфиг | `ishulker.admin` |
| `/ishulker version` | Версия плагина | `ishulker.admin` |
| `/ishulker help` | Список команд | `ishulker.admin` |

**Алиасы:** `/ish`, `/ishulk`.

| `ishulker.use` | Открывать шалкеры из руки | `op` |

## Конфигурация

```yaml
enabled: true

settings:
  require-sneak: true
  open-on-air-only: true
  permission: "ishulker.use"
  prevent-nesting: true
  autosave-interval-ticks: 20
```

- `enabled` — глобальный выключатель (меняется командой `/ishulker on|off`).
- `require-sneak` — требовать зажатый Shift.
- `open-on-air-only` — открывать только при ПКМ по воздуху (иначе и по блокам).
- `permission` — право на открытие; пусто — для всех.
- `prevent-nesting` — запрет складывать шалкеры внутрь и двигать открытый шалкер.
- `autosave-interval-ticks` — период автосохранения (20 тиков = 1 сек).

Сообщения плагина находятся в секции `messages` и используют MiniMessage.

## Защита от дюпов

Плагин блокирует:

- перемещение открытого шалкера из его слота;
- shift-клик по шалкерам, смену клавишей хотбара и обмен с оффхендом;
- складывание шалкеров внутрь открытого шалкера;
- выбрасывание шалкера при открытом меню;
- сохранение выполняется при закрытии, выходе, смерти и по таймеру.
